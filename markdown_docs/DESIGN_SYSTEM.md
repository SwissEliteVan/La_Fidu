## Responsive

### Mobile first

- Concevoir d'abord pour mobile.
- Adapter ensuite pour tablette et desktop.
- Tester sur plusieurs appareils.

### Breakpoints

- Mobile : < 768px.
- Tablette : 768px - 1024px.
- Desktop : > 1024px.

### Rè.

- Navigation simplifié·²e sur mobile.
- CTA facilement accessibles.
- Textes lisibles sans zoom.
- Espaces de touch suffisants.
- Images optimisé·²es.

## Performance

- Images compressé·²es.
- Polices limité.
- CSS minimal.
- JavaScript réduit.
- Lazy loading.
- Cache optimisé·².

### Objectifs

- Score Lighthouse > 90.
- Temps de chargement < 3s.
- First Contentful Paint < 1.5s.
- Time to Interactive < 3.5s.
